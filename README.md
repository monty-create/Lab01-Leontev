## Контрольные вопросы
1. **Почему программа может узнать имя компьютера, хотя вы не писали его в коде?**  
   .NET-программа отправляет системный запрос к API операционной системы, которая хранит эти конфигурационные данные.
2. **Какую роль играет операционная система, когда программа запрашивает у неё сведения?**  
   ОС является посредником и выдает программе безопасный доступ к сведениям об оборудовании и среде выполнения.
3. **Что означает «64-битная ОС»?**  
   Это значит, что процессор и ОС работают с 64-битными адресами и могут использовать более 4 ГБ оперативной памяти.
4. **Что показывает Environment.ProcessorCount и обязательно ли это число совпадает с числом физических ядер?**  
   Показывает число логических процессоров (потоков). Оно больше числа физических ядер, если процессор поддерживает многопоточность.
5. **Чем память процесса (WorkingSet) отличается от всей оперативной памяти компьютера?**  
   WorkingSet — это память, выделенная ОС конкретно под этот изолированный процесс, а не вся физическая RAM компьютера.
6. **Почему одна и та же программа без изменений в коде может показать разные результаты на разных компьютерах?**  
   Потому что код опрашивает параметры окружения (ОС и железо) того конкретного устройства, на котором выполняется в данный момент.
